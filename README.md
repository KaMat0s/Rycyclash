# Rycyclash
RecyClash é um jogo 2D em Java que une diversão e consciência ambiental. O jogador controla um coletor e deve pegar apenas resíduos recicláveis que caem do topo da tela, evitando os não recicláveis. A dificuldade cresce com o tempo, treinando reflexos e o descarte consciente de forma lúdica.
